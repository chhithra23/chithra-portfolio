Case Study 1

Built to get cited,
not just ranked.

We used a brand-new SaaS site with zero built-in authority as a live test bed for AEO. Instead of chasing rankings alone, we targeted best-of and comparison keywords, the exact query types AI engines pull their answers from, and structured every page to be citation-ready.

The real point was what it taught us, and how that transfers to Mailmodo: which on-page and technical choices actually earn an AI citation, and which best-of keywords in our space still have no clear answer for AI to cite, openings Mailmodo could go after first.

In six months: 80+ pages optimized, 400+ backlinks built, 276K Search Console impressions.

Case Study 2

An influencer-scouting engine
that runs itself.

Built in Gumloop. One keyword in, and the whole pipeline (discovery, AI vetting, outreach and logging) runs on its own across four platforms.

01 · Discover

Four platforms, in parallel

Finds influencers with 1,000+ followers on X, Instagram, TikTok and YouTube from one keyword, then merges the results into one block.

02 · Score

AI runs a 5-point fit check

03 · Outreach

A personalized email, per influencer

Writes a short, human-sounding outreach email for every shortlisted influencer.

04 · Log

Straight into Google Sheets

Appends every influencer and their outreach email to the connected spreadsheet.

Case Study 3

Tracking what ChatGPT, Claude
and Gemini actually cite.

The same keyword goes to three AI engines with one identical prompt, asking each to research it and hand back the sources it actually used. Everything gets normalized, scored, deduped and logged into a living spreadsheet.

01 · Prompt

Same prompt, three engines

ChatGPT, Claude and Gemini each research the keyword and run their own live web search in parallel, isolated so one failure never breaks the run.

02 · Extract

JSON first, regex fallback

A Code node flattens each response into one format, then pulls out the source list, with a regex fallback for models that answer in prose.

03 · Dedupe & score

One scoreboard across all three engines

Normalizes and merges URLs, scoring each by citation count and average rank across platforms.

04 · Log

Appended to a live tracker

Every citation and a run log get written straight to Google Sheets.

Honest limitations: Gemini sometimes returns redirect-wrapper URLs instead of the real source, and tracking params can create duplicate entries. There's also no guarantee a model lists every source it used, only what it says it used, capped at 20.
Built with
Gumloop GPT-4o-mini Claude Sonnet 4.6 Gemini 2.5 Flash Brave Search (SERP) Google Sheets
