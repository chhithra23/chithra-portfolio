Automation · Growth Ops

An influencer-scouting engine
that runs itself.

Built in Gumloop: type in one keyword and the whole pipeline — discovery, AI vetting, personalized outreach, and logging — runs on its own across four platforms at once.

01 · Discover

Four platforms, in parallel

Dedicated nodes search X/Twitter, Instagram, TikTok and YouTube simultaneously for influencers with 1,000+ followers matching a keyword (e.g. "email marketing", swappable for any niche) — up to 20 profiles per keyword on X, 10 on Instagram and YouTube, 5 per hashtag on TikTok.

02 · Consolidate

One merged, labeled block

A Combine Text node stitches all four platforms' results into a single structured block, clearly sectioned by platform, ready for analysis.

03 · Score

AI runs a 5-point fit check

An Ask AI node grades every influencer on engagement consistency, genuine comments, audience alignment, natural product integration and niche authority — a Total Fit Score out of 25. Only 15/25+ survive, alongside an estimated median-views and a benchmark price (median views × $0.008).

04 · Structure

Clean, structured fields

An Extract Data node parses the AI's analysis into: handle, platform, followers, median views, benchmark price, tier, total fit score, checklist results and a fit summary.

05 · Outreach

A personalized email, per influencer

A batch Ask AI node writes a short, human-sounding outreach email for each shortlisted influencer — referencing their niche and Mailmodo's value prop, and closing with a CTA to share their media kit.

06 · Log

Straight into Google Sheets

A Google Sheets node appends every influencer's data plus their outreach email as a new row in the connected spreadsheet — ready for the outreach team to send.

Automation · AEO / AI Search

Tracking what ChatGPT, Claude
and Gemini actually cite.

The same keyword goes to three AI engines with an identical prompt, asking each to research it like a real user and hand back the sources it genuinely used. Everything gets normalized, scored, deduped and logged — turning "what does AI recommend for this keyword" into a living spreadsheet.

3AI engines queried in parallel
20sources checked per engine
50citations logged, one run
01 · Prompt

Same prompt, three engines

The keyword from a form is injected into an identical prompt telling each engine to research it as a normal user would, use web search, answer helpfully, then return up to 20 real sources as a strict JSON array — no invented URLs.

02 · Search

Each platform's own live web search

ChatGPT (gpt-4o-mini) uses OpenAI's built-in web search tool, Claude (claude-sonnet-4-6) uses Anthropic's web search, and Gemini (gemini-2.5-flash) uses Google Search grounding — all three fire in parallel, each fault-isolated so one failing engine never breaks the run.

03 · Normalize

Three response shapes → one format

A small Code node per platform flattens each provider's own envelope — ChatGPT's output field, Claude's content blocks, Gemini's parts[] — into a single {platform, text} shape.

04 · Extract

JSON first, regex fallback

An extractor node first looks for a clean JSON array of sources; when a model answers in prose or markdown instead (common for ChatGPT's inline links), a regex fallback pulls every bare URL out of the text so nothing gets missed.

05 · Dedupe & score

One scoreboard across all three engines

URLs are normalized (lowercase host, stripped www and trailing slash) and merged. Each unique source ends up with which platforms cited it, a citation count, a score (citations ÷ platforms queried), and its average rank per platform.

06 · Log

Appended to a live tracker

Every citation — plus a run log — gets written straight to Google Sheets, giving an ongoing view of who AI engines actually trust for a given keyword.

Honest limitations: Gemini's grounding sometimes returns its own redirect-wrapper URLs instead of the real source, and URLs with tracking params (?utm_source=…) can count as duplicates of the clean link. There's also no guarantee a model lists every source it used — only what it says it used, capped at 20.
